# Backend

NestJS API for the Test Case Generator. See the [repository root README](../README.md) for full setup instructions, architecture notes, and the AI integration strategy.

Quick start:

```bash
cp .env.example .env   # fill in GEMINI_API_KEY and DB credentials
npm install
npm run start:dev
```

Runs on `http://localhost:3001` by default. Health check: `GET /health`.
